Тебе необходимо разработать и развернуть веб-приложение: «GameDev Prompt & Markdown Architect» — интерактивный конструктор системных промптов и Markdown-документации (GDD, Tech Spec) для создания игр с помощью ИИ-агентов (OpenCode, Cursor, Aider).

Имя сайта:
freejam.online/prmpt
проект: PRMPT


### 1. Архитектура и стек
* Фронтенд: SPA на React/Vue 3 или чистый современный JavaScript + Tailwind CSS (Lucide Icons, Marked.js / markdown-it для live-рендеринга, Prism.js / Highlight.js для подсветки кода).
* Бэкенд: Минималистичный и надежный (Node.js/Express или FastAPI/Python) для раздачи статики, сохранения пользовательских пресетов в JSON/SQLite и экспорта zip-архивов.
* Развертывание: Dockerfile + docker-compose.yml (или systemd-сервис с Nginx), готовый к запуску на Ubuntu VPS.

### 2. Ключевой функционал
1. Интерактивный визард генератора (GameDev Wizard):
   - Шаг 1: Концепт (Название, Жанр, Целевой движок: Unity / Godot / Phaser.js / Three.js / Pygame, Кор-механика).
   - Шаг 2: Игровые сущности и механики (Игрок, Враги, Препятствия, Система очков/здоровья, Условия победы/поражения).
   - Шаг 3: Техническая архитектура (Выбор паттернов: Finite State Machine, Event-driven, Entity Component; структура папок).
   - Шаг 4: Форматирование промпта для ИИ (Роль, технические ограничения, запреты, пошаговая стратегия кодинга).

2. Редактор и Split-Screen Live Preview:
   - Левая колонка: форма ввода и выбор параметров.
   - Правая колонка: переключение вкладок сгенерированных файлов с живым просмотром:
     * `GDD.md` (Game Design Document)
     * `TECH_SPEC.md` (Архитектурное ТЗ)
     * `AGENT_PROMPT.md` (Готовый вводный промпт для скармливания в OpenCode)
     * `TASK_1_SCAFFOLD.md` (Первая атомарная итерация разработки)

3. Система пресетов и шаблонов:
   - Встроенные шаблоны: 2D Platformer, Top-Down Arena, Endless Runner, Grid Puzzle.
   - Возможность импорта/экспорта конфигурации проекта в формате `.json`.

4. Экспорт и утилиты:
   - Кнопка «Скопировать промпт в буфер» (в один клик с toast-уведомлением).
   - Кнопка «Скачать ZIP» со всей структурой файлов проекта (`docs/`, `.rules`, `README.md`).

5. Образовательный блок (Prompt Quality Score):
   - Простая эвристическая проверка промпта: наличие роли, стека, критериев приемки (DoD), ограничений на рефакторинг.
   - Подсказки-тултипы: почему агенту нельзя давать слишком широкие задачи и как декомпозировать фичи.

### 3. Требования к UI/UX
